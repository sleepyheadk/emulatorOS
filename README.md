# Описание функций
## ls
### Описание
Команда `ls` на данном этапе реализована как заглушка.
### Примеры использования
**Без аргументов**
```text
~$ ls
ls, args: []
```
**С аргументами**
```text
~$ ls file.txt
ls, args: ['file.txt']
```
## cd
### Описание
Команда `cd` на данном этапе реализована как заглушка.
### Примеры использования
**Без аргументов**
```text
~$ cd
cd, args: []
```
**С аргументами**
```text
~$ cd folder test
cd, args: ['folder', 'test']
```
## exit
### Описание
Завершает работу приложения и закрывает окно.
### Примеры использования
**Без аргументов**
Завершает работу приложения.
```text
~$ exit
```
**С аргументами**
Передает сообщение об ошибке.
```text
~$ exit 123
exit: too many arguments
```
# Обработка ошибок
В программе предусмотрена обработка основных ошибок, которые могут возникнуть при вводе команды.
**Незакрытая кавычка**
Если аргумент начинается с кавычки, но закрывающая кавычка отсутствует, парсер сообщает об ошибке
```text
~$ ls "file.txt
error: unclosed quote
```
**Лишние аргументы команды exit**
Команда `exit` не принимает аргументы. При их наличии программа выводит сообщение об ошибке
```text
~$ exit 123
exit: too many arguments
```

## Параметры командной строки
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--vfs` | путь к физическому расположению VFS | не задан |
| `--script` | путь к стартовому скрипту | не задан |

Оба параметра необязательны. Параметры передаются через `run.bat`:
```text
run.bat --vfs vfs --script scripts\startup_ok.txt
```
При неизвестном параметре программа выводит сообщение об ошибке и завершается.

## Отладочный вывод
При запуске все заданные параметры выводятся в консоль и в окно эмулятора перед первым промптом:
```text
[DEBUG] Параметры запуска:
[DEBUG]   --vfs    = examples\vfs
[DEBUG]   --script = examples\scripts\startup_ok.txt
```
Если параметр не задан, выводится `None`.
Если VFS не найдена (путь не существует или не является папкой) или скрипт не удалось прочитать, в отладочный вывод добавляется строка `[DEBUG] ОШИБКА: ...`. Окно при этом всё равно открывается.

## Стартовый скрипт
Стартовый скрипт — текстовый файл в кодировке UTF-8, по одной команде эмулятора в строке.

- Команды выполняются последовательно сразу после запуска.
- Каждая строка «печатается» после промпта, выполняется и выводит результат, имитируя диалог с пользователем. Между строками небольшая пауза (`SCRIPT_DELAY_MS` в `app.py`).
- Пустые строки и строки, начинающиеся с `#` (комментарии), пропускаются.
- Ошибочные строки (неизвестная команда, незакрытая кавычка, неверные аргументы) не прерывают скрипт: сообщение об ошибке выводится, выполнение продолжается со следующей строки.
- Пока выполняется скрипт, ввод с клавиатуры заблокирован. После окончания скрипта ввод разблокируется и работа продолжается в интерактивном режиме.
- Если в скрипте есть команда `exit`, окно закрывается.

Пример `examples/scripts/startup_ok.txt`:
```text
# комментарий
ls
cd /home
ls "my folder" -l
exit
```
Результат:
```text
~$ ls
ls, args: []
~$ cd /home
cd, args: ['/home']
~$ ls "my folder" -l
ls, args: ['my folder', '-l']
~$ exit
```

Пример `examples/scripts/startup_errors.txt` (со строками с ошибками):
```text
ls -l
foo
cd "unclosed
exit extra_arg
cd /home
```
Результат:
```text
~$ ls -l
ls, args: ['-l']
~$ foo
foo: command not found
~$ cd "unclosed
error: unclosed quote
~$ exit extra_arg
exit: too many arguments
~$ cd /home
cd, args: ['/home']
~$
```

## Скрипты для тестирования параметров
Скрипты ОС (`.bat`) находятся в папке `tests`. Каждый вызывает эмулятор с определённым набором параметров. Их можно запускать из любого места, так как каждый переходит в корень проекта.

| Скрипт | Что проверяет |
|--------|---------------|
| `test_no_params.bat` | запуск без параметров |
| `test_vfs.bat` | только `--vfs` |
| `test_script.bat` | только `--script` |
| `test_all_params.bat` | оба параметра, скрипт с ошибочными строками |
| `test_errors.bat` | несуществующие VFS и скрипт, неизвестный параметр |

Запуск (из корня проекта, в PowerShell):
```text
.\tests\test_all_params.bat
```
