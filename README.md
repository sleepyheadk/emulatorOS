# О программе
Эмулятор для языка оболочки ОС.
Этап 1. REPL
Цель: создать минимальный прототип. Большинство функций в нем пока
представляют собой заглушки, но диалог с пользователем уже поддерживается.
Требования:
1. Приложение должно быть реализовано в форме графического интерфейса
(GUI).
2. Заголовок окна должен содержать имя VFS.
3. Реализовать парсер, который корректно обрабатывает аргументы в
кавычках.
4. Реализовать команды-заглушки, которые выводят свое имя и аргументы: ls,
cd.
5. Реализовать команду exit.
6. Продемонстрировать работу прототипа в интерактивном режиме.
Необходимо показать примеры работы всей реализованной
функциональности, включая обработку ошибок.
7. Результат выполнения этапа сохранить в репозиторий стандартно
оформленным коммитом.
# Запуск приложения
Для запуска приложения нужно запустить файл run.bat в папке проекта.
# Структура проекта
- parser.py — разбирает строку пользователя на команду и аргументы.
- shell.py — находит нужную команду и передаёт ей аргументы.
- commands.py — содержит доступные команды.
- app.py — отвечает за взаимодействие с пользователем через GUI.
- main.py — создаёт объекты приложения и запускает главный цикл.
# Описание функций
## ls
### Описание
Команда `ls` на данном этапе реализована как заглушка.
### Примеры использования
**Без аргументов**
```text
~$ ls
ls, args: []
```
**С аргументами**
```text
~$ ls file.txt
ls, args: ['file.txt']
```
## cd
### Описание
Команда `cd` на данном этапе реализована как заглушка.
### Примеры использования
**Без аргументов**
```text
~$ cd
cd, args: []
```
**С аргументами**
```text
~$ cd folder test
cd, args: ['folder', 'test']
```
## exit
### Описание
Завершает работу приложения и закрывает окно.
### Примеры использования
**Без аргументов**
Завершает работу приложения.
```text
~$ exit
```
**С аргументами**
Передает сообщение об ошибке.
```text
~$ exit 123
exit: too many arguments
```
# Обработка ошибок
В программе предусмотрена обработка основных ошибок, которые могут возникнуть при вводе команды.
**Незакрытая кавычка**
Если аргумент начинается с кавычки, но закрывающая кавычка отсутствует, парсер сообщает об ошибке
```text
~$ ls "file.txt
error: unclosed quote
```
**Лишние аргументы команды exit**
Команда `exit` не принимает аргументы. При их наличии программа выводит сообщение об ошибке
```text
~$ exit 123
exit: too many arguments
```

Все автоматические тесты находятся в директории `tests`.
Для запуска всех тестов из корневой директории проекта используется команда:
```text
pytest
```
